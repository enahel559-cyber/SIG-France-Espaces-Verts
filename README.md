# 🌳 Analyse et cartographie des espaces verts à Paris

## Présentation

Projet réalisé avec Python pour analyser et cartographier des espaces verts à Paris.

## Objectifs

- Manipuler des données géographiques
- Utiliser Python pour l'analyse de données
- Créer une carte interactive
- Visualiser différents types d'espaces verts

## Technologies

- Python
- Pandas
- GeoPandas
- Folium
- OpenStreetMap

## Fonctionnalités

- Carte interactive
- Marqueurs géographiques
- Informations sur les espaces verts
- Catégories
- Statistiques
- Regroupement des marqueurs

## Lancer le projet

Installer les bibliothèques :

```bash
python -m pip install pandas geopandas folium
